# Features

## Tasks and projects

- Nested projects, folders, tasks and notes.
- Sequential, parallel and single-action containers; task dependencies.
- Due dates, defer dates, reminders and recurrence, including repeats relative to completion.
- Nested tags, on-hold tags, flags and priorities.
- Drag to reorder or move items; keyboard navigation and inline editing.
- Undo/redo and a 30-day Recently Deleted view.

## Views and planning

- Inbox, Today, Flagged, All, Forecast, Plan, Review, Time, Tags and Nearby.
- Saved perspectives with filters and sorting.
- Basic filters and nested AND/OR/NOT expressions.
- Daily time budgets, task estimates and project review intervals.
- Time tracking with sessions, task segments, pauses, editing, time notes and CSV reports.

## Notes and files

- Rich Markdown notes, inline images, comments and attachments.
- Notes projects, task/note conversion and recipe views with serving adjustments.
- Database and attachment export/import; Markdown export for notes and task checklists.
- Per-device attachment caching: on demand, thumbnails or all files.

## Apps and customization

- Web/PWA, desktop and Android apps.
- Local SQLite storage for offline work; no account required for local use.
- Desktop quick-add hotkey and tray menu.
- Simple, Standard, Advanced and Custom interface presets.
- Themes, accent colors, gestures and separate desktop/mobile feature visibility.

## Sync and collaboration

These features require a sync server:

- Multi-device sync, including optional settings and saved-view sync.
- Shared projects and tasks, multiple assignees and read/write permissions.
- Cross-workspace federation, disabled by default.
- Scoped API keys, personal keys and external webhooks.
- CalDAV and iCal feeds, Home Assistant and Telegram integration.
- AI task commands, filters and agent responses through a configured provider.
- Push notifications and shared location sources.

Local reminders depend on app and platform support. Uncached attachments and
external integrations need a connection. GPS recording is optional; background
recording depends on the native app and distribution variant.
